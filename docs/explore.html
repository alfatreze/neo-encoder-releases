Does adding another step pay off?

These checks are what the Architect editor can use to warn you about steps that add time but little benefit.

How to read it. Every dot is one recipe on this image. Left means a smaller file, up means better quality, so the best recipes sit up and to the left. Large dots joined by the dashed line are the best trade-offs. Hover a dot for details. Technical note: the quality score is NEO's SSIM × 100; the perceptual option is SSIMULACRA2 and is only available for finalists that have been re-scored.

Reading the table. Each cell shows the new file size, the saving versus the original, and a perceptual score where 100 means identical (about 90 is visually lossless, 70 is still high quality). "exact" means every pixel is unchanged. app is the real ImageOptim app run with the author's settings; neo-lossy and neo-lossless are NEO's matching recipes.
